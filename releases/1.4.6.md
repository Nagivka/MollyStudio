## MollyStudio 1.4.6.0

- Обновлён интерфейс редакторов и настройки; панели можно изменять по размеру.
- Упрощён экспорт: весь проект в PNG, без лишних полей и режимов.
- Исправлено восстановление ярлыка Windows после обновления.
- Доработаны генератор 3D-надписей и инструменты диагностики.

### Какой файл скачать

- Windows: **x64-setup.exe**.
- macOS: **arm64.dmg** для Apple Silicon, **x64.dmg** для Intel.
- Linux: **AppImage** для запуска без установки; **deb** для Debian/Ubuntu, **rpm** для систем с RPM. Выбирайте x64 или arm64 под свой процессор.

Служебные файлы обновления скачивать вручную не нужно. Source code — исходники, а не приложение.
