# Установка MollyStudio

| Система | Какой файл выбрать |
| --- | --- |
| Windows x64 | `MollyStudio-<версия>-x64-setup.exe` |
| Mac с процессором Apple | `MollyStudio-<версия>-arm64-mac.dmg` |
| Mac с процессором Intel | `MollyStudio-<версия>-x64-mac.dmg` |
| Ubuntu или Debian | `MollyStudio-<версия>-<архитектура>-linux.deb` |
| Linux с поддержкой AppImage | `MollyStudio-<версия>-<архитектура>-linux.AppImage` |

Архитектура `x64` соответствует Intel и AMD, `arm64` — 64-битным ARM-процессорам. На Mac тип процессора указан в меню Apple → «Об этом Mac». В Linux его показывает `uname -m`: `x86_64` соответствует `x64`, `aarch64` — `arm64`.

В Windows запустите EXE. На Mac откройте DMG и перетащите MollyStudio в «Программы». Для обычной установки скачанной Mac-версии требуется выпуск, подписанный Developer ID и проверенный Apple. Минимальная заявленная версия системы — macOS 13.

В Ubuntu и Debian установите скачанный пакет командой `sudo apt install ./MollyStudio-<версия>-<архитектура>-linux.deb`, подставив имя файла. AppImage можно запустить после `chmod +x` для скачанного файла. Если дистрибутив ограничивает запуск AppImage через FUSE или sandbox и доступен DEB, используйте DEB. В архиве `tar.gz` лежит распакованная версия для ручного запуска.

Для переноса проекта сохраните его как `.mlst`, скопируйте файл на другую машину и откройте в MollyStudio. PNG — готовое изображение для игры или публикации. Для дальнейшего редактирования храните `.mlst`.

Mac-сборка без Developer ID проверяет новые версии при запуске, если автоматическая проверка включена в настройках. Когда обновление готово для вашего процессора, в главном меню и настройках появляется кнопка «Скачать DMG». Она открывает загрузку через браузер. Откройте DMG, закройте MollyStudio и перенесите новую версию в «Программы», подтвердив замену приложения. Проекты и профиль настроек сохраняются. macOS может запросить разрешение на запуск скачанной версии. Проверить наличие обновления вручную можно в разделе «О программе».

Для автообновления AppImage держите файл в папке, в которую у вашей учётной записи есть право записи. После обновления предыдущий исполняемый файл сохраняется рядом с суффиксом `.previous`. Если новая версия не запускается, закройте её, сохраните её файл под другим именем и верните предыдущей копии имя с расширением `.AppImage`.
