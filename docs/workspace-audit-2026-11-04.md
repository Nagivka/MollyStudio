# Аудит MollyStudio — 4 ноября 2026

Проверена рабочая версия 1.4.5 / Windows 1.4.5.0 на Electron 45. Изменения и установщик остаются локальными: отправка исходников, тегов и публикация релиза не выполнялись.

## Исправления

- Устранена подтверждённая утечка закрытого проекта надписей: редактор больше не удерживает его через `displayedProject`. После закрытия освобождаются сцена, GPU-текстуры и загруженные пользователем изображения; небольшой общий кэш встроенных ресурсов сохраняется.
- При ошибке загрузки ресурсов или графики появляется действие «Повторить загрузку». Успешное восстановление убирает ошибку и возвращает управление. Потеря контекста экспорта не повреждает последнюю готовую надпись.
- Параметры надписей учитывают возможности выбранного шрифта и строки. Кернинг, торцевые элементы, крипер и материал подзаголовка не предлагаются там, где они не применимы. Значения сохранённых проектов не удаляются.
- Сочетания клавиш 3D-редактора используют общую проверку фокуса. Открытые диалоги и ввод через IME не переключают инструменты.
- Ошибки отключённого накопителя распознаются отдельно. Нативная ошибка экспорта модели больше не описывается как ошибка PNG. Сбой записи сохраняет несохранённое состояние и позволяет повторить операцию.
- Диалог сохранения с простым именем файла открывается в «Документах», вместо рабочей системной папки Windows. Явно заданные пути сохраняются.
- Экспорт BBModel выделен из большого редактора в `TitleModelExporter.js`; определение доступности параметров — в `TitleControls.mjs`.
- Добавлены длительные сценарии открытия/закрытия с проверкой сборки мусора, проверка отключения накопителя, масштаб интерфейса 200% и воспроизводимая проверка настоящего NSIS-установщика.
- README исправлен по текущему состоянию: 3D-редактор, праздничные даты, скрытая диагностика и действующая система обновлений.

## Оставшееся замечание зависимостей

`npm audit --omit=dev` не обнаружил уязвимостей. Полный `npm audit` сообщил 15 moderate-позиций в дереве средств сборки, связанных с одним [предупреждением minimatch GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249). Они не входят в production-зависимости приложения.

Доступный electron-builder 26.18.0 пока приводит старые ветки minimatch. Автоматическое предложение npm откатывает electron-builder до 20.23.1; оно не применялось. Принудительная подмена всех веток minimatch на 11 может нарушить вызовы старого API. До совместимого исправления сборка должна использовать только доверенные шаблоны из репозитория. Предупреждение не скрыто и не выдано за исправленное.
