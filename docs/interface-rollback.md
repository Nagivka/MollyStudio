# Возврат интерфейса 1.2.5

Источник оформления — исходники из `dist/MollyStudio-Setup-1.2.5.exe`. Версия во вложенном `app.asar/package.json` проверена: `1.2.5`. Установщик не запускался.

Восстановлены четыре CSS-файла, разметка главного меню, редактора, настроек, создания проекта и генератора, а также контроллер главного меню, ripple и диалог подтверждения. Из старой HTML-разметки исключена только ссылка на удалённый `js/desktop-bridge.js`: используется текущий Electron preload. Контрольные суммы эталона находятся в `tests/fixtures/interface-1.2.5.json`.

Удалены адаптеры Material Web, экспериментальные Expressive-компоненты, их bundle, зависимости и обслуживающие команды. Исправления хранения, истории, инструментов, общего рендерера кнопок, нормализации акцентов и клавиатуры сохранены. SVG заголовков и контекстное меню слоёв согласованы с прежней разметкой. Нативные поля меню сохраняют управление стрелками.

Номер приложения остаётся 1.3.0 / 1.3.0.0: возвращено оформление, не формат данных и не весь код старого приложения. Упаковка и сборка не выполнялись.

## Резервные копии

- `.rollback/interface-before-restore-1.2.5.zip` — интерфейс, проверки и конфигурация перед откатом.
- `.rollback/interface-1.2.5-reference.zip` — исходные файлы оформления из установщика.

Архивы исключены из проверки исходников и системы контроля версий. Файлы проектов и пользовательские настройки не изменялись.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm test` | 62 теста: файлы эталона, темы, инструменты, история, сохранение и восстановление |

| Playwright | Главное меню, редактор, настройки, генератор: 1280×800; создание проекта: 760×780 |
| Действия Playwright | Создание проекта из меню, светлая тема и акцент, редактирование HEX градиента, изменение размера холста с сохранением пропорций |

Страницы имели ожидаемые заголовки и содержимое, ошибок JavaScript в проверенных действиях не обнаружено. Визуальная проверка использовала текущие исходники через локальный HTTP-сервер и Playwright MCP: Browser plugin недоступен. Кеш браузера отключён перед повторной проверкой. Electron использовал отдельный временный профиль; пользовательские окна не перезагружались.

Отдельные ESLint, Prettier, Vitest и TypeScript проверки в проекте не настроены. Проверку синтаксиса JavaScript и ссылок ресурсов выполняет `npm run audit`. Визуальная проверка не охватывает все сочетания размеров окна, тем и состояний инструментов.
