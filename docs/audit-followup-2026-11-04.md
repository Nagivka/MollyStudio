# Продолжение аудита — 4 ноября 2026

Версия остаётся 1.4.5 / 1.4.5.0. Релиз не публиковался. Предыдущий полный прогон описан в `workspace-audit-2026-11-04.md`; это дополнительная проверка последующих исправлений.

## Исправлено

### Загрузка изображений надписей

Воспроизведён случай, когда последняя вкладка надписей закрывалась во время декодирования пользовательской текстуры. Запоздавший `onload` снова помещал изображение в уже очищенный кэш. Повторное открытие могло использовать старый запрос, а его завершение — удалять запись новой загрузки.

`TitleRenderer` теперь проверяет принадлежность запроса перед сохранением изображения и удалением записи загрузки. Закрытие сцены снимает незавершённые запросы пользовательских ресурсов; завершение старого запроса не затрагивает новую сцену. Общие исходные ресурсы шрифтов продолжают загружаться. Полное освобождение renderer также запрещает запоздавшему декодированию наполнять кэш.

Пять регрессионных тестов проверяют позднюю загрузку, повторное открытие, запоздавшую ошибку, общий кэш и уничтожение renderer. До исправления четыре из них падали, после — все проходят.

### Продолжение проверок

Раньше `npm run check -- --resume` проверял только порядок имён сценариев. После изменения исходников он мог повторно засчитать результаты прежней версии.

Добавлена контрольная сумма содержимого `src`, `scripts`, `tests`, `.github` и конфигурации проекта, включая новые файлы без коммита и бинарные ресурсы. Отдельно сравниваются план команд, версия Node, платформа и архитектура. Старые отчёты без таких данных не используются. Изменения входных файлов во время прогона останавливают его с ошибкой. Сам отчёт записывается заменой временного файла.

Пять тестов проверяют изменения одинакового размера, новые файлы, переименования, ресурсы, lock-файл, связанные каталоги, циклы ссылок, повреждённые отчёты и повторное использование только успешного префикса. Отчёты, профили и собранные EXE не сбрасывают результаты.
