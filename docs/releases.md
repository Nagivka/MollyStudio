# Выпуск MollyStudio

Исходники: **Nagivka/MollyStudio**, приватный репозиторий. Готовые EXE и контрольные суммы: **Nagivka/MollyStudio-Releases**, публичный репозиторий. Не меняйте видимость исходников. Публичные архивы Source code относятся только к репозиторию релизов.

## Однократная настройка

В приватном репозитории уже есть окружение `UPDATES_REPO_TOKEN` с одноимённым секретом. В Settings → Environments → UPDATES_REPO_TOKEN проверьте/обновите этот секрет: fine-grained GitHub token с доступом только к `MollyStudio-Releases`, разрешение Contents: Read and write. Не добавляйте токен в исходники, приложение или публичный репозиторий. Установите срок действия и обновляйте секрет до его истечения. Job публикации использует это окружение; проверочная сборка доступа к нему не получает.

`GITHUB_TOKEN` используется только для чтения приватного репозитория. Старый `UPDATES_SIGNING_KEY` для этого процесса не используется. Подпись Windows и обновление внутри приложения — отдельные задачи; этот workflow их не включает.

Workflow **Check release repository access** проверяет доступ существующего токена к новому репозиторию, не загружая файлы и не изменяя релизы. Значение секрета в лог не выводится.

## Проверочная сборка

Actions → Build Windows portable → Run workflow. Оставьте Publish выключенным. Проверки, сборка и приватный артефакт EXE + SHA256 выполняются без токена публикации. Артефакт хранится семь дней. Исходники, логи диагностики, профили и проекты не входят в публичные вложения.

## Новая версия

1. Измените `package.json` и `package-lock.json`: например, `1.4.1`. В `electron-builder.cjs` установите `buildVersion: '1.4.1.0'`.
2. Создайте `releases/1.4.1.md` с изменениями для пользователей.
3. Отправьте изменения в приватный репозиторий. Создайте там тег `v1.4.1` на проверенном коммите и отправьте тег. Либо запустите workflow вручную с Publish на нужной ветке.
4. Workflow проверит типы, ядро, модульные тесты, статический аудит и запуск Electron, затем соберёт portable меньше 100 MB.
5. Только EXE и его SHA256 загружаются в черновик публичного релиза. После проверки размера и SHA256 GitHub публикует релиз.

Существующий релиз автоматически не перезаписывается. При ошибке загрузки остаётся черновик для проверки; перед повторным выпуском проверьте его вручную. Если токен отсутствует или истёк, публикация завершится ошибкой, но приватный артефакт сохранится.

Ссылка для форума всегда одна: https://github.com/Nagivka/MollyStudio-Releases/releases/latest

Electron включает renderer-код в приложение. Приватность GitHub не делает JavaScript в EXE недоступным для анализа.
