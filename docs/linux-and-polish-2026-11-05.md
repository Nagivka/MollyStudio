## Linux

- RPM добавлен к обычной Linux-сборке на x64/arm64, к проверке SHA256 и к разрешённым дополнительным файлам публикации. Изменённый после сборки RPM блокирует подготовку релиза.
- Отдельная команда `npm run dist:flatpak` собирает bundle на freedesktop/Electron BaseApp 25.08 с Zypak, X11/Wayland, WebGL, звуком и доступом к рабочим файлам. Эта команда не заменяет существующие AppImage-каналы и не публикует ничего во Flathub.
- Ручной приватный workflow `linux-distributions.yml` готовит проверки упакованного редактора в Ubuntu 22.04, Debian 12/13, Fedora 43, Arch и openSUSE Tumbleweed, а также сборку/установку Flatpak на x64/arm64.

**Ограничение:** на текущем Windows-ПК нет Linux runtime. Новые Linux jobs ещё не запускались; предыдущий доступ к GitHub Actions ограничен оплатой/лимитом. RPM и Flatpak в этом проходе не собраны. Контейнерные сценарии не доказывают работу каждой оболочки и видеокарты. Нативные Linux пакеты требуют совместимые системные библиотеки; Flatpak расширяет охват за счёт собственного runtime, но не даёт гарантии буквально для всех дистрибутивов.
