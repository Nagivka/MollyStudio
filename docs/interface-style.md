# Единое оформление приложения

Эталон — принятый интерфейс 1.2.5: Google Sans, тональные поверхности, округлые панели, кнопки с полным скруглением и поля с обводкой. Главное меню и компоновка редактора сохранены.

## Общие компоненты

- `www/css/material-you.css` — исходные токены оформления.
- `www/css/application-ui.css` — единые кнопки, компактные действия, поля, списки, ползунки, переключатели, флажки, цветовые кружки, меню и варианты диалогов.
- `www/css/buttons.css` — общий макет обоих генераторов, ограниченный контейнерами `.buttons-win-shell` и `.btn-gen-modal`.
- `www/js/ui/ApplicationUI.js` — общий запуск клавиатурной навигации и ripple. Используются исходные HTML-элементы и события.
- `www/js/ui/ControlState.js` — синхронизация визуального выделения кнопок и `aria-pressed`.

Все пять HTML-страниц подключают общий слой компонентов после своих стилей. Внутренние диалоги наследуют его. Поля остаются нативными HTML-контролами; подмены через Shadow DOM нет. Диалоги файлов операционной системы обслуживает Electron.

## Исправления

- Во всех одиночных select предусмотрен отступ 32 px под стрелку. Исправлены конфликтующий padding компактных списков и наложение стрелки на «Пиксельное». При ограниченной ширине текст сокращается перед областью стрелки.
- Исправлен скрытый `input[type=color]` в точках градиента текста и обоих генераторов. Кружок показывает текущий цвет, после редактирования HEX значение обновляется.
- Сегменты сетки, стиля и заливки модального генератора, заливки/тени текста и пресеты угла — настоящие кнопки с клавиатурным управлением и состоянием выбора.
- Оба семейства переключателей имеют геометрию 48×28, доступны с Tab и переключаются пробелом. Фокус отображается на видимой дорожке.
- Удалён неиспользуемый старый блок стилей генератора с конфликтующими `!important`. Актуальная модалка использует общий макет с отдельной прокручиваемой областью и доступной кнопкой импорта.
- В узких окнах генератор располагает колонки вертикально; вкладки встроенных настроек переходят в горизонтальную полосу.
- Ripple устанавливается один раз в каждом окне, работает и на динамических кнопках и пропускает отключённые элементы.

## Проверки

`npm test` проверяет логику и контракт общего оформления. `npm run test:electron` проверяет пять страниц в отдельных тестовых окнах, сохранение/открытие, историю, инструменты, отступы select, геометрию переключателей, предпросмотр цветов, доступность сегментов и видимость импорта. `npm run audit` проверяет синтаксис JS, импорты и локальные ресурсы. ESLint, Vitest, Prettier и TypeScript в проекте не настроены.

| Команда | Результат |
| --- | --- |
| `npm test` | 67 тестов прошли |
| `npm run test:electron` | 54 сценария прошли |
| `npm run audit` | 906 файлов, ошибок нет |

Визуальная проверка выполнена через Playwright MCP на текущих исходниках (`http://127.0.0.1:4175`): Browser plugin недоступен. Проверены пять страниц, встроенные настройки и генератор, тёмная/светлая темы, размеры 1280×800, 760×780 и 560×760. Заголовки и содержимое соответствовали страницам; ошибок JavaScript в проверенных действиях не было. Пробелом переключены настоящий switch настроек и сегмент генератора; в поле «Пиксельное» проверено место под текст и стрелку; цвета градиента проверены визуально после ввода HEX.

Проверки не охватывают все возможные сочетания размеров, десяти тем и состояний инструментов. Полная исходная версия до унификации сохранена в `.rollback/interface-before-unification.zip`. Сборка приложения не выполнялась.
