Временная сборка `0.0.1` получила подписанный манифест и AppImage `0.0.2` через локальный HTTP-сервер, установила обновление и перезапустилась. Новый процесс подтвердил версию `0.0.2`, прежний путь исполняемого файла, сохранённый слой и автокопию несохранённого слоя. Использованы временный ключ и отдельный тестовый загрузчик. Production-ключи, публичные релизы, настоящая сеть GitHub и FUSE этим сценарием не проверялись. Тесты и сборки выполнялись только в GitHub Actions.

Прогон `41876161209` завершился успешно на коммите `2d9273c`. Все пять заданий прошли, включая повторно запущенное задание Apple Silicon. Проверки и сборки этой серии выполнялись на серверах GitHub.

В [прогоне `41876161209`](https://github.com/Nagivka/MollyStudio/actions/runs/41876161209) Windows runner сохранил редактируемые `.mlst` и эталонные PNG для GUI, префикса и 3D-надписи. На Ubuntu x64 и arm64 файлы открылись, сохранили параметры и остались редактируемыми. PNG двухмерных проектов совпали пиксель в пиксель. Для 3D проверка допустила небольшое расхождение между графическими драйверами.

В том же прогоне macOS Intel проверила GUI и префиксы из Windows, пересохранение и экспорт. Запуск готового приложения и открытие проекта через LaunchServices прошли. WebGL недоступен на виртуальном Intel runner, поэтому отрисовка 3D на нём остаётся за пределами проверки. На Apple Silicon прошли перенос всех трёх проектов, включая 3D, сборка и запуск готового приложения.

Обе архитектуры Ubuntu прошли запуск DEB под Weston при 125%, копирование текста в системный буфер, импорт PNG через событие перетаскивания и открытие `.mlst` через зарегистрированный `.desktop`. Сценарий AppImage проверил действующий Chromium sandbox, запуск до и после замены, сохранение старого файла при неверной контрольной сумме, откат при ошибке планирования перезапуска и копию `.previous`. Использовался `extract-and-run` с двумя копиями одной версии. FUSE и сетевое обновление между двумя выпусками в этом сценарии не проверялись.

Эта серия проверок выполнялась только на серверах GitHub. Для отдельного Mac подготовлен [сценарий проверки Ventura и Intel WebGL](platform-compatibility.md), для пользователей — [инструкция по установке и переносу проектов](install.md).

## Исправления по результатам нативных запусков

- Согласованы реальные имена архивов: electron-builder использует разные значения архитектуры для AppImage/DEB и отдельный Mac bundleVersion. Метаданные обновлений больше не ссылаются на несуществующие имена.
- Проверка дистрибутива учитывает состав Linux Electron 45: ANGLE встроен в бинарный файл, отдельные libEGL/libGLESv2 не требуются.
- Отсутствующий Apple secret больше не превращается в путь к сертификату. Ad-hoc сборки отделены от Mac с постоянной подписью и не получают автоматическое обновление.
- Ошибка нативной сборки завершает процесс с ненулевым кодом, а не продолжает проверку неполного результата.
- Перед настройкой sandbox в CI явно загружается закреплённый Electron. Playwright запускается с `chromiumSandbox: true`.
- DEB устанавливается через APT с разрешением зависимостей. На чистом Ubuntu первоначально отсутствовали libnotify4 и libsecret-1-0; после установки зависимостей готовое приложение прошло проверку.
- Проверки исходников и фикстуры корректно работают с LF, Meta и чувствительной к регистру файловой системой.
- Системное меню Mac учитывает переназначение и отключение сочетаний. Для обычных букв системные ускорители не регистрируются, чтобы не перехватывать ввод текста; изменение и начальная загрузка настроек синхронизируют меню через ограниченный IPC.

## Неподтверждённое и внешние ограничения

Графический рендеринг 3D на Intel Mac с настоящим драйвером ещё не проверен. Виртуальная машина не предоставила WebGL ни с одним из проверенных графических режимов. Сценарий подтвердил сообщение об ошибке, сохранность документа, доступность повтора загрузки и работоспособность обычного холста. 28 проверок настоящего WebGL прошли на Apple Silicon и обеих архитектурах Ubuntu.

Для публичной Mac-версии не предоставлены Developer ID и данные нотариальной проверки Apple. Подготовленный ad-hoc вариант не даёт бесшовного прохождения Gatekeeper и не используется для автоматического обновления. Системные ограничения и настройка подписи описаны в [совместимости](platform-compatibility.md).

Linux проверен на Ubuntu 24.04 через X11/Xvfb и Weston Wayland. Другие дистрибутивы, композиторы и файловые менеджеры требуют отдельных проверок. Автоматическое обновление Mac/Linux проверено подписанными фикстурами. Переход Mac между двумя Developer ID сборками ещё требует сертификата.

Production-аудит npm: 0 уязвимостей. Известное замечание minimatch в инструментах electron-builder остаётся в dev-зависимостях и в приложение не включается.

Артефакты текущего проверенного коммита доступны в [приватном прогоне GitHub Actions](https://github.com/Nagivka/MollyStudio/actions/runs/41876161209). В каждом архиве есть контрольные суммы SHA-256 и отчёты сборки. Локальная папка `dist/native` содержит пакеты предыдущего коммита `822ab71`. Папка `dist/native/darwin-arm64-preview` содержит ещё более раннюю сборку Apple Silicon.
