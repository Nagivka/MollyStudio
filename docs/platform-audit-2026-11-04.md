## Исправления по результатам нативных запусков

- Согласованы реальные имена архивов: electron-builder использует разные значения архитектуры для AppImage/DEB и отдельный Mac bundleVersion. Метаданные обновлений больше не ссылаются на несуществующие имена.
- Проверка дистрибутива учитывает состав Linux Electron 45: ANGLE встроен в бинарный файл, отдельные libEGL/libGLESv2 не требуются.
- Отсутствующий Apple secret больше не превращается в путь к сертификату. Ad-hoc сборки отделены от Mac с постоянной подписью и не получают автоматическое обновление.
- Ошибка нативной сборки завершает процесс с ненулевым кодом, а не продолжает проверку неполного результата.
- Перед настройкой sandbox в CI явно загружается закреплённый Electron. Playwright запускается с `chromiumSandbox: true`.
- DEB устанавливается через APT с разрешением зависимостей. На чистом Ubuntu первоначально отсутствовали libnotify4 и libsecret-1-0; после установки зависимостей готовое приложение прошло проверку.
- Проверки исходников и фикстуры корректно работают с LF, Meta и чувствительной к регистру файловой системой.
- Системное меню Mac учитывает переназначение и отключение сочетаний. Для обычных букв системные ускорители не регистрируются, чтобы не перехватывать ввод текста; изменение и начальная загрузка настроек синхронизируют меню через ограниченный IPC.

## Неподтверждённое и внешние ограничения

Финальный полный прогон Mac не завершён. GitHub несколько раз не выделил hosted runner для macOS 15 и отменил задания до выполнения команд; повторный запуск не помог. Задания на macOS 26 также были отменены сервером до начала команд. Очередной прогон остаётся в очереди. Это внешняя недоступность проверочной среды, а не успешный результат тестов; очередь не считается подтверждением совместимости.

3D на Intel Mac с настоящим графическим драйвером отдельно не проверен. Если виртуальная машина не предоставляет WebGL после проверки backend, сценарий явно отмечает непроверенные операции и проверяет безопасный отказ. Это не заменяет тест рендеринга на Intel Mac с GPU.

Для публичной Mac-версии не предоставлены Developer ID и данные нотариальной проверки Apple. Подготовленный ad-hoc вариант не даёт бесшовного прохождения Gatekeeper и не используется для автоматического обновления. Системные ограничения и настройка подписи описаны в [совместимости](platform-compatibility.md).

Linux проверен на Ubuntu 24.04 через X11/Xvfb. Все дистрибутивы, окружения Wayland, файловые менеджеры, принтеры и драйверы этим прогоном не сертифицируются. Автоматическое обновление Mac/Linux проверено подписанными фикстурами; настоящий переход Mac между двумя Developer ID сборками ещё требует сертификата.

Production-аудит npm: 0 уязвимостей. Известное замечание minimatch в инструментах electron-builder остаётся в dev-зависимостях и в приложение не включается.

Linux-пакеты сохранены в приватных Actions artifacts на семь дней. Копирование больших ZIP на этот ПК прервалось из-за соединения. Автоматическая проверка запретила удалить три частичных ZIP в `.test-output/native-downloads`; они исключены из Git и сборок.
