# Аудит генератора надписей MollyStudio

Область проверки: документ надписи, геометрия, 13 шрифтов и кириллица,
309 материалов, 58 наложений, 148 повторяющихся текстур, управление сценой,
история, сохранение MLST, экспорт PNG и BBModel, интерфейс четырёх основных тем.

## Исправления

| Система | Проблема и исправление |
| --- | --- |
| История | Поздняя загрузка материала могла отменить более новое состояние. Каждый запрос восстановления теперь отменяет предыдущий, включая быстрый путь из кэша. Ошибка загрузки возвращает последний полностью готовый документ. |
| Курсор истории | Ошибка асинхронного восстановления возвращает не только документ, но и правильные стеки отмены/повтора. Для цепочки ещё не завершённых отмен сохраняется общий контрольный снимок; посторонние новые команды не перезаписываются. |
| Незавершённый жест | Отмена во время перетаскивания по оси или отложенного изменения камеры отменяет текущий жест, сохраняя предыдущую команду истории. |
| Принадлежность ресурсов | Смена проекта закрывает библиотеку. Поздний выбор ресурса не меняет другой проект; импорт изображения также проверяет выбранную строку. |
| Меню | «Готовые оформления» сначала открывают нужную вкладку, а команда выбора текстуры открывает библиотеку материалов надписи. |
| Масштаб интерфейса | Вкладки не обрезаются в Minecraft-темах при масштабе 150%; панель сохраняет минимальную рабочую ширину до перехода в вертикальную компоновку. |
| Память истории | Снимки надписи были скрыты в замыканиях и не учитывались общим лимитом памяти. Команды теперь передают данные `before` и `after` штатному механизму подсчёта. |
| Геометрия | У замкнутых моделей масштаб подзаголовка применялся после поворота строки. Теперь локальные масштабы осей применяются до поворота, как у исходных моделей. |
| Компоновка строк | Разные шрифты, масштабы и диакритика могли вызвать пересечение обычных строк. Расстояние теперь рассчитывается по фактическим границам; пустые строки сохраняют свой интервал. |
| Пустой текст | В отдельных шрифтах оставались краевые элементы, рамки и пустые узлы сцены. Пустые строки больше не создают геометрию. |
| Управление | Горячие клавиши сцены действовали поверх диалогов. Диалоги теперь изолированы; W/E/R/F работают по физическим клавишам и при русской раскладке. |
| Перетаскивание | Сохранение или смена документа во время жеста могли завершиться поздним откатом. Перед завершением документа жест фиксируется и освобождает захват указателя. |
| Материалы | После смены шрифта мог оставаться недоступный вариант наложения. Нормализация убирает недоступный вариант, сохраняя загруженные пользователем наложения. |
| Кэш | Удаление изображения из общего кэша оставляло карту прозрачности во втором рендерере. Теперь соответствующие данные удаляются в обоих экземплярах. |
| Производительность | Ключи геометрии и материалов повторно обрабатывали полные данные загруженных изображений. Камера теперь использует компактные ключи и переиспользует GPU-буферы. Проверка изображений использует слабые ссылки на объекты настроек. |
| Ввод | Ограничение textarea учитывало только символы BMP. Исправлено ограничение UTF-16: три строки, до 64 символов Unicode в каждой. Превышение лимита при вводе явно отмечается и блокирует сохранение; введённый текст остаётся доступен для исправления. |

## Проверки

- `npm test` — модульные проверки проекта и новые регрессионные случаи.
- `npm run test:titles` — управление, история, создание, сохранение, темы и размеры окна.
- `npm run test:titles:precision` — пропорции, камера, PNG, масштаб 2× и точность осей.
- `npm run test:titles:fonts` — все исходные семейства, материалы, чёткость текстур.
- `npm run test:titles:materials` — библиотеки, импорт, градиенты, наложения и кэш.
- `npm run test:titles:cyrillic` — исходная кириллица, языки строк и совместимые оформления,
  выбор/изменение моделей, MLST, встроенные текстуры BBModel и образцы в галереях.
- `npm run test:titles:audit` — задержки и ошибки загрузки, гонки истории,
  клавиатура, память, завершение жеста, все повторяющиеся текстуры,
  надпись из 192 букв и отказ от чрезмерного размера экспорта.
- `npm run typecheck`, `npm run core:verify`, `npm run audit`.
- `npm run test:responsive` — 212 сочетаний страниц, тем, размеров и масштаба, включая границу вертикальной компоновки надписей на русском и английском.
- `npm run test:visual:components` — 216 случаев в 12 темах при 100/125/150%, включая все вкладки надписей.
- `node scripts/compare-title-reference.mjs .test-output/title-reference/plugin.js` — 180 сравнений геометрии и UV с проверенной по SHA256 версией исходного плагина 1.10.4.

Сценарии Electron используют временный профиль. Проверены размеры содержимого
1000×700, 1280×900 и 1920×1080. Изображения сохраняют прозрачность;
при сравнении повторного рендера допускается округление RGB на один уровень
у сглаженных краёв, с точным совпадением альфа-канала и параметров документа.
Эти проверки относятся к текущей среде Electron; они не заменяют проверку
всех существующих видеодрайверов и будущих пользовательских конфигураций.

## Языки строк и исходная кириллица

Неудачный перенос английских текстур и самодельных кириллических форм удалён.
В каждой строке используется один язык; разные строки могут иметь разные языки.
Для русского доступны исходные Minecraft Ten Cyrillic и Five Bold Cyrillic,
для украинского — Ten Cyrillic. Шрифты, материалы и наложения фильтруются по
языку выбранной строки. Старый смешанный текст сохраняется для ручной правки,
а сохранение и экспорт блокируются до исправления языка строки.

## Углублённый аудит 31 октября 2026

Дополнительно исправлены случаи, которые не выявлялись обычным созданием и экспортом надписи:

- Начальная загрузка проекта сразу нормализует документ и временно блокирует зависимые элементы. Старый 3D-кадр не выдаётся за новый проект. После ошибки загрузки управление освобождается, документ остаётся доступен для повторной попытки.
- Дерево сцены сохраняет фокус после переключения видимости, блокировки и раскрытия. Добавлены стрелки, Home/End и доступный вход с клавиатуры. Сворачивание родителя выбранного объекта не убирает все точки фокуса; переход к объекту прокручивает его в видимую часть дерева.
- После отказа рендера активное поле камеры или преобразования возвращается к фактически применённому значению. Незавершённый ошибочный рендер не меняет последнюю готовую картинку и историю. Некорректный пользовательский ввод при этом остаётся доступен для исправления.
- Готовая 2D-картинка принимается слоем только после завершения рендера; убрано дополнительное копирование полноразмерного bitmap поверх прежнего изображения.
- BBModel сохраняет фактические центры вращения групп и частей после перемещения, вращения и масштабирования. Вершины записываются относительно собственного центра, с сохранением исходных мировых координат, UV и сваренных вершин. Семантика сверена с [реализацией Mesh в Blockbench](https://github.com/JannisX11/blockbench/blob/master/js/outliner/types/mesh.js); добавлена независимая проверка мировых координат экспортированной сцены.
- Перемещение камеры учитывает полезную рамку PNG, а не поля вокруг неё. Запрос пересечения оси вне кадра возвращает отсутствие пересечения вместо исключения.
- Удалена повторная подписка на восстановление графического контекста.

## Удаление декоративных объектов

По запросу пользователя удалены все пять декоративных моделей, их библиотека,
128 оформлений, 17 наложений, превью, каталоги и инструмент синхронизации.
Удалено 307 файлов ресурсов. Нормализация старых MLST игнорирует эти объекты
и их преобразования, сохраняя надпись. Проверка рабочего процесса переписана
для текстовой сцены; тест контрольных сумм проверяет оставшиеся 885 файлов.
Результаты численных прогонов выше относятся к состоянию до удаления.

## Повторный аудит после удаления значков — 4 ноября 2026

Проверена текущая текстовая сцена: 13 шрифтов, 309 материалов, 58 наложений,
148 повторяющихся текстур и 885 зеркалированных файлов ресурсов.
Старые MLST с удалёнными декоративными объектами открываются; текст, настройки
строк и преобразования букв сохраняются, старые значки не восстанавливаются.

Исправления:

- При возвращении к уже отрисованному проекту завершённая загрузка больше не оставляет сообщение «Загружается материал…». Реальное предупреждение о неподдерживаемом символе сохраняется. Оба случая закреплены отдельными сценариями Electron.
- Повторный запуск экспорта BBModel не открывает параллельные диалоги и не создаёт повторную запись. Кнопка временно блокируется, после отмены или ошибки записи снова доступна; повторная попытка проверена тестом.
- Имя BBModel использует общую обработку имён Windows: зарезервированные имена вроде `CON`, запрещённые знаки и чрезмерная длина обрабатываются так же, как при других сохранениях. Название самого проекта не изменяется.
- При потере WebGL-контекста видимого окна новый растровый снимок мог примениться раньше, чем завершалась подготовка сцены предпросмотра. Теперь оба рендерера проверяются до замены готового документа. Отказ сохраняет прежние данные, изображение, значение поля и позицию истории. После восстановления контекста снова доступны редактирование и экспорт; ожидание контекста не запускает повторяющиеся ошибочные перерисовки.
