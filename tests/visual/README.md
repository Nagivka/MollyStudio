# Визуальные проверки

Сценарии находятся в `scripts/visual-regression.cjs` и используют реальный Electron с отдельным временным профилем. Эталоны привязаны к версии Chromium, шрифтам и платформе.

`npm run test:visual:audit` запускает режим `--capture`: проверяет геометрию, пиксельный холст и все 12 тем на пяти страницах при разных размерах и масштабах. Снимки сохраняются в `.test-output/visual/captures`, отчёт — в `.test-output/visual/report.json`. Можно ограничить страницу: `npm run test:visual:audit -- --page=editor`. Режим не сравнивает и не изменяет утверждённые эталоны.

Для текущего Electron утверждённые эталоны ещё не созданы. Старые снимки другого движка не подтверждают текущий интерфейс. `npm run test:visual:update` применяется только после запуска и просмотра результата. `npm run test:visual` требует совпадения версии Chromium, платформы и контрольных сумм шрифтов с манифестом эталонов.

Параметр `--language=en` включает английский интерфейс. Его результаты находятся отдельно в `.test-output/visual-en`, будущие эталоны — в `tests/visual/baselines/win32-electron45-en`. По умолчанию проверяется русский. После просьбы пользователя работать без ПК новые запуски окон и запись эталонов приостановлены.
