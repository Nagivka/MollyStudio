# Аудит тем Minecraft / Minecraft Light

29.10.2026. Проверены обе Minecraft-темы, русские и английские подписи, обычный и увеличенный масштаб интерфейса. Существующие игровые эталоны сохранены отдельно. Эта проверка касается интерфейса MollyStudio, а не растрового содержимого пользовательских проектов.

## Исправления

1. Бегунок ON/OFF поднят на **1 CSS px** относительно прежнего положения. Сдвиг одинаков для двух состояний, двух имён компонента (`md-switch`, `m3-switch`) и обоих вариантов темы. Горизонтальный ход и отметки I/O сохранены. Регрессионная проверка теперь проверяет этот сдвиг, а не старое центрирование.
2. В многострочных группах выбора стиля кнопок и режима тени восстановлены рамки всех элементов. Прежнее удаление левой границы у всех кнопок кроме первой оставляло начало второй строки без рамки. Однострочные сегменты по-прежнему соединены; группы с переносом используют полностью обрамлённые элементы и небольшой промежуток.
3. Выпадающий список палитры в свойствах текста освобождён от встроенного оформления. Старые `border-radius:6px`, фон и цвета из `style` перекрывали тему. Теперь оформление задаётся классом и согласуется с остальными select; обычные темы сохраняют компактную плотность этого поля.
4. В Minecraft-темах отключено размытие под модальными окнами. Затемнение сохранено, пиксельные детали заднего плана не размываются.
5. Радиокнопки в окне изменения размера холста получили квадратную рамку и квадратную отметку выбранного варианта. Круглый градиент общего Material-оформления больше не попадает в тему Minecraft.
6. Полная проверка темы и проверка её контролов включены в `npm run check`, чтобы эти регрессии проверялись и в следующих изменениях.

## Область проверки

- Все девять разделов настроек, включая нижние участки прокрутки: оформление, эффекты, холст, инструменты, экспорт, Discord, данные, горячие клавиши, информация о программе.
- Свойства текста, фигуры и сгенерированной кнопки; вкладки текста/фона префиксов, градиент текста и тени, фактура фона. Панели проверены по высоте с прокруткой.
- Встроенный генератор кнопок, галереи GUI и префиксов, игровой предпросмотр GUI, экспорт, фактура слоя, история, обе утилиты и подтверждение действия.
- Изменение размера холста, выбор шаблона, перекраска и встроенная форма нового проекта.
- Реальные pointer/keyboard-состояния контролов: hover, удерживаемое нажатие, disabled, переключение клавишей Space и выбор сегмента.
- Корректное удаление временных пиксельных декораций после перехода к обычной теме.
- Основные страницы и диалоги дополнительно прогнаны через существующие сценарии геометрии и адаптивности; проверяются обрезания подписей, пересечения контролов, переполнение, выход диалогов за границы и отсутствие пиксельной замены иконки.

## Воспроизведение

Из корня проекта:

```powershell
npm run test:minecraft-controls
npm run test:minecraft-theme
npm run test:minecraft-ranges
npm run test:visual:components
npm run test:visual:interactions
npm run test:responsive
npm test
npm run audit
```

Сценарии Electron работают во временных профилях, пользовательские проекты и настройки не меняют. Полный отчёт и снимки темы находятся в `.test-output/minecraft-theme-audit`, отчёт по состояниям контролов — в `.test-output/minecraft-controls`. Внутри отчёта сохраняются контекст экрана, размеры/масштаб, язык, позиция прокрутки и найденные нарушения.

Итоговый прогон: **260 экранных состояний** полного аудита темы без найденных нарушений; **227 проверок контролов**, **32 проверки делений ползунков**, **108 сочетаний визуальных компонентов**, **216 сочетаний взаимодействий**, **96 сочетаний адаптивной вёрстки** и **494 модульные проверки** прошли. Статический аудит проекта не обнаружил проблем. Эти числа относятся к разным уровням проверки и не суммируются в число независимых функций приложения.

Визуально просмотрены полученные снимки настроек, генератора, утилиты градиента, изменения размера и свойств. Проверки не являются обещанием отсутствия ошибок на любой комбинации видеодрайвера и масштаба Windows. Светлая тема остаётся адаптацией: отдельного светлого игрового эталона в собранном комплекте нет. Установщик и portable-сборка не создавались.
