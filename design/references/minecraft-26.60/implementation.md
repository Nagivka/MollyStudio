# Перенос правил контролов в MollyStudio

29.10.2026. Изменения ограничены двумя Minecraft-темами. Игровые эталоны не заменены скриншотами приложения.

## Внесённые изменения

- Разделено оформление приподнятых действий, утопленных полей, плоских вкладок и соединённых сегментов. Вкладки больше не получают фаску и зелёную заливку обычной активной кнопки.
- Переключатель: трек 60 × 28 px, квадратный бегунок 32 × 32 px, ход 28 px. По уточнению пользователя бегунок смещён на **1 px выше центра трека** в обоих состояниях; в свободной половине показывается только соответствующая состоянию пиксельная отметка I/O. Переключение с клавиатуры сохраняется.
- В сегментах убраны промежутки и удвоенные общие границы. Выбранная поверхность и её подпись ниже на 4 px, снизу короткая белая отметка; внешняя область нажатия остаётся на месте.
- Одновариантные select оформлены светлыми кнопками выбора. Для шеврона оставлено 36 px; его рисунок имеет размер 12 × 8 px без растягивания до квадрата. Поля редактирования остаются тёмными и утопленными. Сохраняется нативная работа select, центральная игровая модалка не реализовывалась.
- У недоступных кнопок и переключателей используются отдельные непрозрачные цвета. Контролы не просвечивают фоном из-за общей opacity.
- Для настроек введена более свободная плотность: кнопки 48 px, сегменты 56 px, бегунок ползунка 32 px. В редакторе остаются компактные действия 40 px и бегунок 24 px.
- Заполнение и деления ползунка используют ту же переменную ширины, что и его бегунок. Убрана зависимость расчёта заполнения от одного жёстко заданного размера 24 px.
- У закрытой секции тёмная поверхность, у открытой — основная серая. Индикатор раскрытия выравнивается справа.
- Убрана дробная межбуквенная прибавка Material, которая смещала последующие пиксельные буквы с сетки. Поставленные пользователем файлы шрифтов сохранены; отсутствие субпиксельного сглаживания на всех конфигурациях Windows этим не гарантируется.
- Библиотека шрифтов префикса использует полную ширину строки и адаптивные карточки. Названия не обрезаются, соседнее поле интервала не растягивается на высоту всей библиотеки.
- Исправлены рамки outlined-кнопок и цвет наведения на кнопку закрытия окна.

Результаты следующего полного прохода: [аудит темы](audit.md).

## Проверки

| Команда | Результат |
| --- | --- |
| `npm test` | 494 модульных проверки прошли |
| `npm run test:minecraft-controls` | 198 проверок: геометрия, доступные и недоступные состояния, переключение клавишей Space, выбор сегмента, фактические настройки/префиксы/холст при разных размерах и масштабах |
| `npm run test:minecraft-ranges` | 32 пиксельные проверки делений: два размера бегунка, две темы, масштаб 100%/125%, начало/конец двух диапазонов |
| `npm run test:visual:components` | 108 сочетаний: холст, префиксы и диагностика во всех 12 темах при масштабе 100%/125%/150% |
| `npm run test:responsive` | 96 сочетаний: главное окно, холст, GUI, префиксы, настройки, создание проекта, кнопки и утилиты |

Сценарии Electron работали в отдельных временных профилях. Скриншоты и подробные результаты сохранены в `.test-output/minecraft-controls`, `.test-output/visual-components`, `.test-output/responsive` и `.test-output/minecraft-range-scenarios.json`. Просмотрены снимки реальных настроек и префиксов, а также стенд контролов. Сборка дистрибутива не запускалась.

Это результаты функциональной и геометрической проверки, а не подтверждение абсолютного попиксельного совпадения со всеми состояниями игры. Для него ещё нужны отдельные эталоны удерживаемого нажатия, точная сверка метрик используемых шрифтов и дополнительные размеры игрового интерфейса; светлая тема остаётся адаптацией, поскольку отдельного светлого игрового эталона нет.
